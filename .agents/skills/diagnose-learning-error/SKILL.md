# 학습 오류 진단

정답을 주기 전에 추론의 어느 지점에서 문제가 시작됐는지 찾는다.

## 입력 확인

1. [운영 정책](../../../guides/agent/operating-policy.md)을 읽는다.
2. 다음을 받는다.
   - 해결하려던 문제 또는 설명할 개념
   - 학습자가 실제로 시도한 내용
   - 예상한 결과와 실제 결과
   - 가장 불확실하다고 느끼는 지점
3. 시도 내용이 없으면 첫 단계나 현재 생각을 먼저 보여 달라고 한다.

## 자기 진단

학습자에게 다음 중 무엇에 가까운지 추측하게 한다.

- 개념: 원리나 전제가 잘못됨
- 절차: 원리는 알지만 계산·코딩 단계에서 실수함
- 전략: 문제 특성에 맞지 않는 접근을 선택함
- 표현: 표, 수식, 데이터 구조나 상태 표현이 문제를 가림
- 복합: 두 종류 이상이 연결됨

자기 진단이 맞으면 스스로 수정할 기회를 먼저 준다. 부분적으로 맞으면 확인할 지점 하나만 좁혀 준다.

## 도움 제공

진단 후 오류 유형에 맞는 최소 도움만 제공한다.

- 개념 오류: 실제 원리와 현재 전제의 차이
- 절차 오류: 처음 어긋난 단계
- 전략 오류: 현재 접근이 맞지 않는 문제 특성
- 표현 오류: 더 적합한 표현 방식
- 복합 오류: 가장 앞에서 발생한 오류부터 순서대로 처리

단순 오타, 들여쓰기나 명백한 산술 실수에는 긴 진단 절차를 강요하지 않는다.

## 종료

```text
오류 유형
처음 어긋난 지점
학습자가 수정한 내용
다음에 스스로 찾을 확인 규칙
추가 도움이 필요할 경우 호출할 스킬
```

수정 코드를 자동 작성하거나 결과를 기록하지 않는다.
