# 설명 우선 점검

학습자의 설명을 AI 설명으로 대체하지 말고 가장 약한 연결을 찾는다.

## 준비

1. [운영 정책](../../../guides/agent/operating-policy.md)과 [범위와 출처 정책](../../../guides/agent/scope-and-source-policy.md)을 읽는다.
2. 확인할 개념과 학습자가 작성한 설명을 받는다.
3. 설명이 없으면 먼저 자신의 말, 구조도 또는 의사코드로 작성하게 한다.

## 질문 방식

1. 설명에서 맞는 부분과 가장 취약한 연결 하나를 찾는다.
2. 한 번에 질문 하나만 한다.
3. 다음 순서로 필요한 질문을 고른다.
   - 용어가 무엇을 뜻하는가?
   - 입력이 어떤 과정을 거쳐 출력이 되는가?
   - 왜 그 단계가 필요한가?
   - 어떤 조건에서 설명이 깨지는가?
   - 앞뒤 개념과 어떻게 연결되는가?
4. 같은 공백에 최대 세 차례만 질문한다.
5. 진전이 없으면 연결 힌트, 직접 개념 설명, 유사 예제, 종료 중 하나를 사용자가 선택하게 한다.

## 평가

다음 항목을 구분한다.

- 개념 용어의 정확성
- 메커니즘의 인과 연결
- 입력·출력과 상태 변화
- 실패 조건과 한계
- 현재 주차 범위를 벗어난 주장

사실 오류는 출처로 확인한다. 표현이 다르다는 이유만으로 틀렸다고 판정하지 않는다.

## 종료

학습자에게 수정된 설명을 짧게 다시 작성하게 한다. 이후 다음만 요약한다.

```text
유지할 설명
수정한 연결
남아 있는 공백
다시 확인할 질문
```

완료 여부를 대신 결정하거나 기록하지 않는다.
