# 학습 기록 반영

승인된 기록만 최소 범위로 수정한다. 새로운 학습 평가를 수행하거나 이해 수준을 임의로 높이지 않는다.

## 실행 조건

다음 조건을 모두 확인한다.

1. 사용자가 `$learning-record-manager`를 명시적으로 호출했다.
2. 반영할 내용이 대화에서 이미 검토됐거나 요청 안에 정확히 제시됐다.
3. 사용자가 `반영해줘`, `기록해줘`처럼 파일 수정을 명확히 요청했다.
4. 대상 파일 또는 기록 종류를 식별할 수 있다.

하나라도 충족하지 않으면 파일을 수정하지 않고 필요한 정보만 묻는다.

## 사전 확인

1. [운영 정책](../../../guides/agent/operating-policy.md)과 [평가와 기록 정책](../../../guides/agent/evaluation-and-record-policy.md)을 읽는다.
2. 대상 파일의 현재 내용을 읽는다.
3. 다음을 구분해 보여준다.

```text
대상 파일
추가할 내용
바꿀 내용
그대로 보존할 내용
충돌하거나 불명확한 내용
```

사용자가 같은 요청에서 정확한 대상·변경 내용과 승인을 모두 제시했다면 승인을 반복해서 묻지 않는다. 범위가 모호하면 수정 전에 확인한다.

## 반영

- 저장소 루트에서 정규화한 최종 경로가 `progress/**` 또는 사용자가 정확히 지정한 `learning-notes/**` 안에 있는지 확인한다.
- 다른 경로, `..`로 허용 범위를 벗어나는 경로와 심볼릭 링크·재분석 지점을 통한 우회는 거부한다.
- 승인된 파일과 항목만 수정한다.
- 기존 미해결 질문과 오개념을 근거 없이 삭제하거나 완료 처리하지 않는다.
- AI 문장으로 사용자의 자기 설명을 대체하지 않는다.
- 무지원 결과와 도움 받은 결과를 분리한다.
- 날짜, 점수, 실행 결과, 출처 또는 학습 시간을 추정해서 채우지 않는다.
- 기존 사용자 문장과 구조를 가능한 한 보존한다.

## 파일 선택

- 현재 위치와 재개점: [current-state](../../../progress/current-state.md)
- 보류 질문: [question-backlog](../../../progress/question-backlog.md)
- 확인된 오개념과 재검증: [misconception-log](../../../progress/misconception-log.md)
- 완료 준비도 평가: `../../../progress/checkpoints/` 아래의 지정 파일
- 개인 복습: 사용자가 정확히 지정한 `../../../learning-notes/` 아래 경로

## 완료 보고

```text
수정한 파일
반영한 승인 내용
보존한 기존 내용
반영하지 않은 내용과 이유
```

요청하지 않은 다음 학습 단계를 시작하거나 다른 스킬을 자동 호출하지 않는다.
