# 학습 세션 계획

오늘 할 일을 대신 결정하지 말고 선택 가능한 범위로 나눠 제안한다.

## 준비

1. [운영 정책](../../../guides/agent/operating-policy.md)과 [세션 상태](../../../guides/agent/session-state.md)를 읽는다.
2. [현재 상태](../../../progress/current-state.md)가 있으면 현재 위치와 이전 중단점을 확인한다.
3. [과정 안내](../../../curriculum/overview.md)가 연결한 현재 주차 문서에서 범위와 완료 조건만 읽는다. 사용자가 다른 주차를 명시했다면 그 주차를 우선한다.
4. 다음 입력을 확인한다.
   - 현재 파트·주차·주제
   - 사용 가능한 시간
   - 새 세션 또는 재개 여부
   - 오늘 원하는 강도나 특별한 목표
5. 핵심 입력이 없으면 하나씩 짧게 묻는다. 기록 파일을 수정하지 않는다.

## 범위 구성

다음 세 범위를 제시한다.

- 최소 범위: 핵심 개념 하나와 확인 활동 하나
- 기준 범위: 최소 범위와 현재 주제의 대표 실험 또는 설명 검증
- 확장 범위: 기준 범위와 선택 가능한 연결 또는 추가 검증

각 범위에 다음을 포함한다.

```text
예상 시간
필수 학습 내용
학습자가 직접 할 행동
완료 조건
자연스러운 중단 지점
```

시간을 채우기 위해 내용을 늘리지 않는다. 현재 완료 조건에 불필요한 내용은 [범위와 출처 정책](../../../guides/agent/scope-and-source-policy.md)에 따라 연결 범위나 선택 심화로 표시한다.

## 재개 세션

이전 중단점이 있으면 새 내용을 시작하기 전에 10~20분의 무지원 회상을 포함한다. 전날 계획을 그대로 유지하지 말고 오늘 가능한 시간으로 다시 계산한다.

## 출력

1. 현재 위치와 재개점
2. 최소·기준·확장 범위 비교
3. 시간이 부족할 때 먼저 제거할 항목
4. 시간이 남을 때 추가할 항목
5. 사용자가 선택할 질문

한 범위를 자동 선택하거나 학습을 바로 시작하지 않는다. 사용자가 선택하면 적절한 다음 스킬과 호출 예시만 안내한다.
