# 단계별 힌트

한 번에 문제를 해결하지 말고 학습자가 다시 시도할 수 있는 최소 단서만 제공한다.

## 준비

1. [운영 정책](../../../guides/agent/operating-policy.md)을 읽는다.
2. 문제, 학습자의 시도, 막힌 지점과 이미 받은 도움을 확인한다.
3. 진행 중인 무지원 평가가 있다면 이 스킬을 실행하지 않는다. 먼저 평가 종료 또는 보조 평가 전환을 선택하게 한다.

## 힌트 단계

1. 진단 질문: 어느 지점에서 무엇을 모르는지 확인
2. 개념 질문: 관련 원리를 떠올리게 하는 질문
3. 원리 상기: 사용할 원리나 제약을 짧게 제시
4. 절차 단서: 다음 한 단계의 방향이나 의사코드
5. 병렬 예제: 숫자·도메인이 다른 유사 문제의 풀이
6. 참고 답안: 사용자가 명시적으로 요청한 경우의 완성 설명 또는 코드

## 운영 규칙

- 현재 필요한 가장 낮은 단계부터 시작한다.
- 힌트를 준 뒤 학습자가 다시 시도할 때까지 다음 단계로 가지 않는다.
- 단계 상승 전 사용자의 요청을 받는다.
- 각 응답에 현재 힌트 단계를 표시한다.
- 6단계 결과는 무지원 이해 증거가 아니라고 명시한다.
- 같은 단서를 표현만 바꿔 반복하지 않는다.

## 종료

학습자가 해결하면 다음을 묻는다.

1. 결정적인 단서는 무엇이었는가?
2. 다음에 같은 막힘을 스스로 찾을 확인 규칙은 무엇인가?

사용한 최고 힌트 단계와 재시도 결과를 대화에 요약하되 자동 기록하지 않는다.
