# 사전 회상

설명부터 제공하지 말고 학습자가 가진 지식을 먼저 꺼내게 한다.

## 준비

1. [운영 정책](../../../guides/agent/operating-policy.md)을 읽는다.
2. 회상할 개념과 범위를 확인한다.
3. 평가가 아니라 학습 전 진단임을 알린다.

## 진행

1. 자료를 닫고 개념, 흐름, 수식 또는 구조를 자유롭게 적게 한다.
2. 필요하면 답하기 전 자신감을 0~100으로 표시하게 한다. 매 질문마다 반복하지 않는다.
3. 제출 전에는 정답이나 핵심 단어를 제공하지 않는다.
4. 제출 후 다음으로 구분한다.
   - 정확하게 회상한 내용
   - 빠진 핵심 연결
   - 오개념 가능성이 있는 내용
   - 아직 확인할 수 없는 내용
5. 정확한 부분을 다시 길게 설명하지 말고 공백과 오개념만 다룬다.
6. 수정 설명을 들은 뒤 자료 없이 한두 문장으로 다시 표현하게 한다.

## 지식이 전혀 없는 경우

학습자가 실제로 처음 접한 내용이면 회상을 강요하지 않는다.

1. 관련 용어를 본 적이 있는지 확인한다.
2. 전체 흐름에서 위치와 역할만 짧게 알려준다.
3. 방금 들은 내용을 자신의 말로 다시 표현하게 한다.

## 종료 출력

```text
회상 성공
누락
오개념 후보
다음에 다시 꺼낼 질문
사용한 AI 도움 수준
```

결과를 진행 기록에 자동 반영하지 않는다.
