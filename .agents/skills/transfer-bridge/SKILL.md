# 개념 전이 확인

원래 예제의 모양을 기억한 것인지, underlying principle을 다른 상황에서도 찾을 수 있는지 확인한다.

## 준비

1. [운영 정책](../../../guides/agent/operating-policy.md)을 읽는다.
2. 방금 학습한 개념, 원래 예제와 현재 이해 증거를 확인한다.
3. 기본 개념을 자기 말로 설명하지 못하면 전이 문제를 시작하지 않고 먼저 보완을 권한다.

## 근거리 전이

같은 원리를 사용하되 숫자, 이름, 데이터 또는 표면 상황을 바꾼 문제를 하나 제시한다. 제출 후 다음을 묻는다.

1. 원래 상황과 같은 점은 무엇인가?
2. 달라진 점은 무엇인가?
3. 적용한 핵심 원리는 무엇인가?

정답을 맞혀도 원리를 설명하지 못하면 `절차적 성공`으로 구분한다.

## 원거리 전이

근거리 전이를 통과한 뒤 게임 서버, 데이터 분석, LLM 애플리케이션 등 표면이 크게 다른 맥락에서 같은 원리를 찾게 한다.

1. 풀기 전에 구조적 유사성을 추측하게 한다.
2. 답안 후 같은 점, 다른 점과 이동하는 원리를 묻는다.
3. 원거리 전이 실패는 예상 가능한 진단 정보로 다루고 학습 실패로 단정하지 않는다.

## 실패 처리

- 근거리 실패: 핵심 원리 설명으로 돌아갈 것을 권한다.
- 근거리 성공·원거리 실패: 다양한 예제 또는 원리의 이유를 보완한다.
- 둘 다 성공: 학습자가 세 번째 적용 맥락을 직접 만들게 한다.

## 종료 출력

```text
근거리 전이: 통과 / 절차적 성공 / 보완 필요
원거리 전이: 통과 / 보완 필요 / 진행하지 않음
명시한 핵심 원리
다음 보완 방향
```

결과를 자동 기록하거나 다음 스킬을 실행하지 않는다.
