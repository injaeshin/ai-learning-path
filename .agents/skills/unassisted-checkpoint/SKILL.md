# 무지원 체크포인트

평가가 시작된 뒤 제출 전까지 학습 내용에 관한 도움을 제공하지 않는다.

먼저 [운영 정책](../../../guides/agent/operating-policy.md)과 [평가와 기록 정책](../../../guides/agent/evaluation-and-record-policy.md)을 읽는다.

## 평가 계약

시작 전에 다음을 확인한다.

- 평가할 범위와 완료 조건
- 평가 유형: 폐쇄형 무지원 / 자료 허용형 무지원 / 보조 평가
- 사용할 수 있는 자료와 실행 도구
- 답변형 AI, 검색과 코드 자동완성의 허용 여부. 이를 사용하면 무지원이 아니라 보조 평가로 전환한다.
- 제한 시간 또는 종료 조건
- 답안 제출 형식
- 평가 항목, 치명 오류 조건과 부분 점수 기준
- 제출 전에는 힌트, 정오 신호와 유도 질문을 주지 않는다는 점

학습자가 계약을 확인한 뒤 평가를 시작한다.

## 문제 구성

- 직전에 함께 푼 문제를 그대로 반복하지 않는다.
- 같은 핵심 원리를 사용하되 입력, 표현이나 실패 조건을 바꾼다.
- 현재 주차 필수 범위 밖 지식을 정답 조건으로 요구하지 않는다.
- 여러 능력을 한 문제에 과도하게 섞지 않는다.

## 평가 중 행동

- 답안 제출 전에는 풀이, 힌트, 핵심 단어, 유도 질문과 정오 반응을 제공하지 않는다.
- 명령 해석이나 파일 위치처럼 학습 내용과 무관한 절차 질문만 답한다.
- 학습자가 도움을 요청하면 다음 중 하나를 먼저 선택하게 한다.
- 다른 학습 스킬을 호출하더라도 같은 선택을 먼저 요구하며, 상태를 바꾸기 전에는 해당 스킬의 도움을 제공하지 않는다.

```text
무지원 평가 종료 후 학습 모드로 전환
현재 결과를 보조 평가로 표시하고 힌트 요청
도움 없이 계속 진행
```

상태를 바꾸기 전에는 도움을 주지 않는다.

## 제출 후 평가

1. 정답과 오류만이 아니라 추론 경로를 확인한다.
2. 무지원으로 확인된 내용과 남은 공백을 구분한다.
3. 함께 푼 문제와 무지원 문제의 성과 차이를 비교한다.
4. 계약상 허용한 도구와 실제 사용한 자료·도구를 확인한다.
5. 필요하면 보완 학습과 다른 변형 문제를 제안한다.

## 종료 출력

```text
평가 범위
평가 유형
허용한 자료와 도구
실제로 사용한 자료와 도구
사용한 도움: 없음 / 보조 평가로 전환
무지원으로 확인된 내용
남은 공백
완료 준비도 제안: 준비됨 / 조건부 준비 / 보완 필요
사용자 진도 선택
```

완료 상태나 체크포인트 파일을 자동 수정하지 않는다.
