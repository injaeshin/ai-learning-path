# AI Learning Path

게임 서버 개발 경험이 있는 개발자가 머신러닝·딥러닝·LLM의 공통 기반을 체계적으로 학습하기 위한 개인 학습 저장소입니다.

## 학습 범위

- 0주차: AI 시스템 전체 지도 (10시간)
- 1~16주차: AI 공통 이해 과정 (주 15시간, 총 240시간)

현재 기준 과정의 총 학습 시간은 250시간입니다. 이전 20주 전환 커리큘럼은 참고 자료로만 보존합니다.

## 시작하기

1. [과정 안내](curriculum/overview.md)에서 학습 범위와 원칙을 확인합니다.
2. [현재 진행 상태](progress/current-state.md)를 확인합니다.
3. [여기서 시작하기](guides/user/start-here.md)의 안내에 따라 첫 세션 범위를 정합니다.
4. 필요한 학습 스킬을 `$skill-name` 형식으로 명시적으로 호출합니다.

## 진행 원칙

- 학습 범위와 다음 단계 진행 여부는 학습자가 결정합니다.
- AI의 도움을 받은 결과와 무지원으로 수행한 결과를 구분합니다.
- 공식 진행 기록은 학습자가 검토하고 승인한 경우에만 변경합니다.
- 하루 학습 종료와 주제 완료는 별도로 판단합니다.

## 저장소 구성

- `curriculum/`: 주차별 학습 목표와 커리큘럼
- `guides/`: 학습자와 에이전트 운영 가이드
- `progress/`: 진행 상태, 체크포인트, 질문과 오개념 기록
- `learning-notes/`: 학습자가 작성하는 개인 노트
- `evaluation/`: 학습 설계와 저장소 검증 결과
- `outputs/`: 커리큘럼 산출물

## 검증

저장소 구조와 문서 링크는 다음 PowerShell 스크립트로 점검할 수 있습니다.

```powershell
.\scripts\validate-learning-repo.ps1
```
