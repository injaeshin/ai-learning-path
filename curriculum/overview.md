# AI 공통 기반 과정 안내

## 현재 기준 과정

이 저장소의 현재 학습 범위는 다음 두 문서다.

1. [0주차 — AI 시스템 전체 지도](week-00.md): 별도 10시간
2. [AI 공통 이해 과정 1~16주](weeks-01-16.md): 주 15시간, 총 240시간

0주차를 포함한 총 학습 시간은 250시간이다. 17~20주 포트폴리오와 선택 프로젝트는 현재 과정에 포함하지 않는다.

## 참고 문서

[기존 20주 전환 커리큘럼](archive/ai-career-transition-curriculum-20-weeks.md)은 이전 설계의 맥락을 보존하기 위한 참고 자료다. 이 문서에 있는 누적 프로젝트와 17~20주 선택 트랙은 현재 진도나 완료 조건의 기준으로 사용하지 않는다.

## 시간 사용 원칙

- 주 15시간과 하루 3시간은 계획을 세우기 위한 기본값이다.
- 실제 하루 학습 범위는 사용자가 가능한 시간과 원하는 강도를 기준으로 선택한다.
- 하나의 학습 주제는 여러 날에 걸쳐 중단하고 재개할 수 있다.
- 하루 학습을 끝내는 것과 학습 주제를 완료하는 것은 서로 다른 결정이다.
- AI는 최소·기준·확장 범위를 제안할 수 있지만 범위를 대신 선택하지 않는다.

## 과정 진행 원칙

- 사용자가 사용자 가이드에서 현재 해야 할 일을 확인한다.
- 필요한 학습 스킬을 `$skill-name` 형식으로 명시적으로 호출한다.
- 도움을 받아 만든 결과와 무지원으로 만든 결과를 구분한다.
- 완료 준비도는 AI가 평가할 수 있지만 다음 단계 진행 여부는 사용자가 결정한다.
- 공식 진행 기록은 사용자가 내용을 승인하고 반영을 요청한 경우에만 변경한다.

## 공통 주차 완료 판단 기준

각 주차의 세부 목표와 과제는 다르지만 완료 준비도는 다음 네 증거를 공통으로 확인한다.

1. 핵심 개념과 데이터 흐름을 자료 없이 자기 말로 설명한다.
2. 해당 주차의 대표 손계산, 마이크로 실험, 구현 또는 실패 분석을 재현한다.
3. 함께 풀었던 것과 다른 변형 문제를 현재 주차가 허용한 도구만 사용해 수행한다.
4. 아직 남은 공백, 사용한 AI 도움과 다시 확인할 시점을 명시한다.

모든 증거가 완벽해야 다음 주차로 갈 수 있다는 의미는 아니다. AI는 `준비됨`, `조건부 준비`, `보완 필요`를 제안하고 사용자가 보완, 진행 중 유지, 다음 단계 진행 또는 완료를 결정한다.

파트 종료 주차의 누적 테스트는 3번의 무지원 변형 문제 증거를 제공하면서 이전 주차 연결까지 확인한다. 누적 테스트가 그 주차의 자기 설명과 대표 실험 증거를 자동으로 대체하지는 않는다.
