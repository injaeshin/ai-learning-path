# 학습 에이전트 행동 검증 결과

- 실행일: 2026-08-13
- 결과: 21개 시나리오 모두 통과
- 대상: `evaluation/behavior-scenarios.md`의 B01~B21

## 검증 방법

문서 교차 검토를 마친 서브 에이전트들에게 시나리오를 나누어 각 요청을 서로 독립된 새 대화로 간주하게 했다. 각 에이전트는 실제 첫 응답을 작성한 뒤 시나리오의 필수 행동, 금지 행동과 판정 기준을 대조했다. 파일 수정은 금지했다.

실제 웹 검색이나 파일 변경이 필요한 시나리오는 부작용 없이 책임 경계를 확인했다.

- B08은 수정할 파일과 보존 범위를 확인하되 검증 중 실제 기록은 바꾸지 않았다.
- B10은 검증할 주장을 분해하고 출처 확인 전 상태를 확정하지 않는지 확인했다. 실제 출처 품질은 학습 세션에서 별도 검증한다.
- 여러 턴이 필요한 B05, B13, B19와 B21은 시나리오에 명시된 선행 상태를 입력 상태로 사용했다.

## 관찰한 핵심 응답

- B05는 `$ai-claim-checker`가 명시 호출돼도 무지원 평가 종료, 보조 평가 전환 또는 계속 중 하나를 먼저 선택하게 했고 출처 검증을 제공하지 않았다.
- B11은 스킬 사용법 질문에 호출 예시만 답하고 세션 계획을 시작하지 않았다.
- B13은 같은 공백에 네 번째 질문을 하지 않고 힌트, 직접 설명, 유사 예제 또는 종료 선택으로 전환했다.
- B18은 학습 증거를 받기 전 학습량과 준비도를 추정하지 않았다.
- B21은 중단한 PEAR 단계, 재시도 결과와 최고 도움 단계를 확인하고 도움받은 구현을 무지원 결과로 승격하지 않았다.

## 한계

이 검증은 에이전트가 작성한 독립 응답을 정책과 대조한 행동 계약 검사다. 실제 장기 세션에서의 상태 유지, 웹 출처의 품질과 파일 수정 권한은 사용 과정에서도 계속 관찰해야 한다.
