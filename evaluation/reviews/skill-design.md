# 스킬 설계 교차 검토

- 검토 관점: 책임, 호출 경계, 메타데이터, 참조와 출처
- 검토 일시: 2026-08-13
- 결론: 수정 후 통과

## 발견 사항

### SD-01 — 스킬 내부 참조 경로가 실행 위치에 의존함

- 심각도: 필수 수정
- 근거: 여러 `SKILL.md`가 저장소 루트 기준 `guides/agent/...`를 사용한다.
- 영향: 현재 디렉터리가 저장소 루트가 아니면 정책을 읽지 못할 수 있다.
- 최소 수정안: 스킬 폴더 기준 `../../../guides/agent/...`와 `../../../progress/...`로 통일한다.

### SD-02 — 명시 호출의 지속 범위가 정의되지 않음

- 심각도: 필수 수정
- 재현: 무지원 평가를 시작한 뒤 이름 없이 `힌트를 줘`라고 한다.
- 영향: 매 턴 호출을 반복해야 하는지, 종료된 스킬이 계속 실행되는지 불명확하다.
- 최소 수정안: 호출은 활동을 시작하고 종료·중단·다른 명시 호출까지 유지된다는 수명 규칙을 정의한다.

### SD-03 — 검증기가 고정 UI 계약과 참조 경로를 충분히 검사하지 않음

- 심각도: 필수 수정
- 영향: 잘못된 UI YAML, 빈 설명과 끊어진 참조가 통과할 수 있다.
- 최소 수정안: 고정 YAML 구조, 설명 길이, 정확한 호출명, U+FFFD와 Markdown 참조 경로를 검사한다.

### SD-04 — 행동 시나리오가 실행 결과가 아니며 일부 스킬이 누락됨

- 심각도: 필수 수정
- 영향: 실제 다회차 동작과 책임 경계가 지켜진다는 증거가 없다.
- 최소 수정안: 누락 스킬과 주요 사용자 여정을 시나리오에 추가하고 새 컨텍스트에서 실행 결과를 남긴다.

## 확인한 긍정 동작

- 13개 이름과 폴더, 호출 가이드가 일치한다.
- 모든 UI 프롬프트가 정확한 스킬 이름을 포함한다.
- 외부 기반 12개 스킬에 고정 commit, 라이선스와 수정 내역이 있다.
- 기록 스킬이 별도 책임으로 격리되어 있다.

## 남은 위험

- 원본 파일과 수정본의 줄 단위 비교는 수행하지 않았다.
- 다중 턴 상태는 실제 실행 전까지 확정할 수 없다.
