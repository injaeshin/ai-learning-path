# 사용자 경험 교차 검토

- 검토 관점: 첫 시작부터 기록 반영까지의 실제 사용 가능성
- 검토 일시: 2026-08-13
- 결론: 수정 후 통과

## 발견 사항

### UX-01 — 첫 진입의 사전 진단 경로가 실행 절차로 연결되지 않음

- 심각도: 필수 수정
- 근거: `start-here.md`, `current-state.md`, `retrieve-first-gate`
- 영향: 진단 범위와 결과를 시작 위치 선택에 쓰는 방법을 사용자가 추측해야 한다.
- 최소 수정안: 0주차 완료 조건과 누적 미니 테스트를 사용하는 호출 예시와 후속 세션 계획을 추가한다.

### UX-02 — 진행 중 일반 이론 질의의 호출 방식이 불명확함

- 심각도: 권장 수정
- 영향: 모든 이론 질문에 스킬이 필요한지 사용자가 판단하기 어렵다.
- 최소 수정안: 현재 범위의 일반 설명은 스킬 없이 직접 질문할 수 있고, 회상·설명 점검·출처 검증만 각각 스킬을 사용한다고 명시한다.

### UX-03 — 보조 스킬 후 코드 실습 복귀 경로가 없음

- 심각도: 권장 수정
- 영향: 힌트 세션에서 끝나거나 코드 실습을 처음부터 반복할 수 있다.
- 최소 수정안: 현재 PEAR 단계, 재시도 결과와 최고 힌트 단계를 전달해 `$guided-code-practice`를 다시 호출하는 예시를 추가한다.

### UX-04 — 주요 사용자 여정의 행동 검증이 일부 누락됨

- 심각도: 권장 수정
- 최소 수정안: 새 대화 재개, 일반 이론 질의, 무수정 코드 리뷰, 증거 부족 주간 회고 시나리오를 추가한다.

## 확인한 긍정 동작

- 첫 문서가 과정·상태·시간·명시 호출 순서를 실제 링크로 안내한다.
- 13개 스킬 모두 언제 쓰고 쓰지 않을지 설명한다.
- 중단 초안과 파일 기록이 분리되어 있다.
- 코드 실습·리뷰와 무지원 평가의 사용자 책임이 분명하다.
- 초기 진행 파일은 실제 시작 전 상태를 명확히 표현한다.

## 남은 위험

- 새 대화 재개, 스킬 전환 후 상태 복원과 출처 품질은 실제 행동 시험이 필요하다.
