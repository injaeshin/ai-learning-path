# 준비도 평가와 기록 정책

## 완료 준비도

AI는 현재 주제의 완료 조건과 실제 학습 증거를 비교해 다음 중 하나를 제안한다.

```text
준비됨
조건부 준비
보완 필요
```

평가 결과는 다음 형식을 사용한다.

```text
완료 준비도
확인된 이해
남은 공백
사용한 AI 도움 수준
권장 보완 활동과 예상 시간
재평가 방법

사용자 선택
- 보완 후 재평가
- 다음 주차로 진행하며 누적 복습에 등록
- 현재 주제를 진행 중으로 유지
- 사용자 판단으로 완료
```

필수 선수 지식 공백을 숨기거나 모호하게 표현하지 않는다. 동시에 AI가 진행을 차단하거나 완료 상태를 자동 기록하지 않는다.

## 평가 증거

증거의 성격을 다음처럼 구분한다.

- 설명을 읽거나 들음
- 질문 또는 힌트를 받아 수행
- 자기 말로 메커니즘 설명
- 자료와 힌트 없이 변형 문제 수행
- 다른 맥락에서 같은 원리 적용

평가를 시작하기 전에 정답 자체를 공개하지 않고 다음을 고정한다.

- 평가 항목과 필수 증거
- 허용 자료와 실행 도구
- 부분 충족 기준
- 현재 개념을 근본적으로 뒤집는 치명적 오류
- 제출과 종료 조건

### 평가 유형

- 폐쇄형 무지원: 문제, 제공 데이터와 비답안형 실행 도구만 사용한다. 답 생성 AI, 코드 자동완성, 해답 검색과 외부 설명 자료는 사용하지 않는다.
- 자료 허용형 무지원: 평가 전에 지정한 공식 문서나 개인 노트와 비답안형 실행 도구를 사용할 수 있다. 답 생성 AI, 해답 검색과 코드 자동완성은 사용하지 않는다.
- 보조 평가: 힌트, 답 생성 AI, 해답 검색, 코드 자동완성 또는 정오 피드백을 사용한 결과다.

평가 유형, 허용 자료·도구와 실제 사용 여부를 결과에 남긴다. 허용되지 않은 도움을 사용하면 보조 평가로 전환한다.

코드 실행 성공, 정답 일치, 학습 시간과 문서 분량만으로 높은 이해 수준을 부여하지 않는다.

## 기록 영역

### 공식 진행 기록

`progress`에는 사용자가 승인한 현재 위치, 완료 증거, 남은 공백, 질문 백로그, 재개점과 다음 재검증 시점을 저장한다.

### 개인 복습 기록

`learning-notes`는 사용자가 자신의 말로 정리하는 공간이다. AI는 사용자가 요청한 경우에만 읽거나 초안·검토를 돕는다.

### 대화 초안

AI가 오늘 종료나 평가에서 만든 정리는 사용자가 승인하기 전까지 파일 기록이 아니다.

## 파일 반영 절차

파일 수정은 `$learning-record-manager`가 명시적으로 호출된 경우에만 수행한다.

1. 사용자가 반영할 초안과 대상 파일을 지정한다.
2. AI가 현재 파일을 읽고 충돌하거나 보존할 내용을 확인한다.
3. AI가 추가·수정할 내용을 사용자에게 다시 제시한다.
4. 사용자가 명시적으로 승인한다.
5. 승인된 범위만 수정한다.
6. 변경한 파일과 보존한 기존 내용을 보고한다.

동일한 요청 안에 명확한 승인과 `반영해줘`가 함께 있으면 다시 승인을 반복해서 묻지 않는다. 대상이나 변경 범위가 불명확하면 파일을 수정하지 않는다.

## 기록 시 금지 사항

- AI의 문장으로 사용자의 이해를 대체
- 무지원과 도움 받은 결과를 합쳐 기록
- 요청하지 않은 기록 파일까지 함께 수정
- 기존 미해결 항목을 근거 없이 완료 처리하거나 삭제
- 날짜, 점수, 실행 결과 또는 출처를 추정해서 채움
- 개인 노트를 공식 완료 증거로 자동 승격
- `progress/**`와 사용자가 지정한 `learning-notes/**` 밖의 파일 수정
- 작업공간 밖으로 나가는 경로 또는 심볼릭 링크를 통한 기록 수정
