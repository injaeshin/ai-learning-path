# 하루 세션 가이드

하나의 학습 주제는 여러 날 진행할 수 있다. 매일 가능한 시간을 먼저 정하고 자연스러운 중단점까지 학습한다.

## 오늘 범위 정하기

```text
$learning-session-planner

현재 2주차 Confusion Matrix를 학습 중이야.
오늘은 2시간 진행하고 싶어.
어제는 Accuracy 계산까지 했어.
중간 흐름을 나누면 어디까지 하는 게 자연스러운지 제안해줘.
```

AI는 다음 세 범위를 제시한다.

- 최소: 오늘 반드시 확인할 핵심
- 기준: 핵심과 대표 실험·설명 검증
- 확장: 시간이 남을 때 추가할 연결 또는 검증

각 범위의 완료 조건과 중단점을 비교해 사용자가 선택한다.

## 새 주제 시작

1. 현재 주차 목표와 제외 범위를 확인한다.
2. `$retrieve-first-gate`로 이미 아는 내용을 먼저 꺼낸다.
3. 새로운 이론을 읽거나 설명을 요청한다.
4. `$explain-first-interrogator`로 자신의 설명에서 공백을 찾는다.
5. 손계산, 마이크로 실험 또는 직접 구현으로 확인한다.

모든 활동을 하루에 끝낼 필요는 없다.

## 진행 중 전환

현재 활동에서 목적이 바뀌면 필요한 스킬을 직접 호출한다.

```text
$diagnose-learning-error 지금 어디서 잘못 생각했는지 진단해줘.
$progressive-hint-ladder 다음 한 단계 힌트만 줘.
$learning-code-review 구현은 끝났어. 수정하지 말고 문제만 검토해줘.
```

한 스킬의 제안을 받았다고 다음 스킬이 자동 실행되지는 않는다.

현재 범위 안의 일반 이론 질문은 스킬 없이 바로 물어도 된다.

```text
Confusion Matrix에서 False Positive가 운영 판단에 어떤 비용을 만드는지 설명해줘.
```

다만 설명을 보기 전에 기억을 꺼내려면 `$retrieve-first-gate`, 자신의 설명을 검토하려면 `$explain-first-interrogator`, 사실과 출처를 확인하려면 `$ai-claim-checker`를 명시적으로 호출한다.

스킬 이름을 인용하거나 사용법을 묻는 것만으로는 실행되지 않는다. 호출된 스킬은 그 활동을 마치거나 중단하거나 다른 스킬을 호출할 때까지 후속 대화에 유지된다.

## 보조 활동 뒤 코드 실습으로 돌아가기

코드 실습 중 오류 진단이나 힌트 스킬로 전환하면 기존 실습은 중단 상태가 된다. 돌아갈 때 `$guided-code-practice`를 다시 호출하고 다음 세 항목을 전달한다.

- 중단한 PEAR 단계
- 보조 활동 뒤 직접 재시도한 결과
- 지금까지 받은 가장 높은 도움 단계

```text
$guided-code-practice

방금 오류 진단을 마치고 Tool Schema 실습으로 돌아갈게.
Explore 단계에서 중단했고, 타입 경계 검증을 직접 다시 시도했어.
받은 도움은 원인 범주를 알려준 수준이 가장 높아.
내 재시도 결과를 확인한 뒤 다음 PEAR 단계만 안내해줘.
```

## 중단하기

시간이 끝났다면 다음처럼 요청한다.

```text
오늘은 여기까지 할게.
완료한 내용, 남은 공백, 사용한 AI 도움과 다음 시작점을 초안으로 정리해줘.
파일에는 아직 기록하지 마.
```

중단 초안에 다음이 들어 있는지 확인한다.

- 오늘 실제로 확인한 내용
- 설명만 들었거나 도움을 받아 수행한 내용
- 아직 확인하지 못한 내용
- 다음에 시작할 정확한 지점
- 재개할 때 자료 없이 먼저 답할 질문

## 다음 날 재개

```text
$learning-session-planner

어제 중단한 2주차 세션을 재개할게.
오늘은 90분 가능해.
먼저 짧게 회상한 뒤 남은 범위를 다시 제안해줘.
```

전날 계획을 그대로 이어가기보다 오늘 시간으로 범위를 다시 정한다.

## 오늘 종료 후 기록

AI가 만든 종료 정리를 검토하고 필요한 표현을 직접 고친다. 파일에 남기려면 별도로 호출한다.

```text
$learning-record-manager

방금 수정한 종료 기록을 current-state에 반영해줘.
질문 백로그에는 내가 표시한 두 질문만 추가해줘.
```

기록 요청이 없으면 대화 초안으로만 남는다.
