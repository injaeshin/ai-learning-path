# 학습 기록 가이드

기록은 세 종류로 나뉜다.

## 대화 초안

AI가 오늘 종료, 답안 평가나 주간 회고에서 만든 정리다. 사용자가 검토하기 전에는 파일에 저장하지 않는다.

## 공식 진행 기록

`progress`에는 다음 세션을 재개하고 누적 공백을 관리하는 데 필요한 최소 사실만 남긴다.

- 현재 파트·주차·주제와 상태
- 확인된 완료 증거와 사용한 도움 수준
- 남은 필수 공백
- 다음 재개점
- 승인된 질문 백로그와 오개념
- 완료 준비도와 사용자의 진도 결정

## 개인 복습 기록

`learning-notes`에는 자신의 말, 예상, 실험 결과와 복습 답안을 남긴다. 모든 파일을 매일 만들 필요는 없다.

```text
learning-notes/
└─ week-02/
   └─ 2026-08-20-confusion-matrix/
      ├─ my-summary.md
      ├─ recall.md
      ├─ experiment.md
      ├─ questions.md
      └─ review.md
```

## 기록 반영 순서

1. AI에게 오늘 정리 초안을 요청한다.
2. 틀린 표현, 과장된 이해와 빠진 내용을 직접 수정한다.
3. 반영할 파일과 항목을 지정한다.
4. `$learning-record-manager`를 호출해 반영을 명시한다.
5. AI가 보여준 변경 범위를 확인한다.
6. 수정된 파일과 보존된 내용을 확인한다.

기록 스킬이 수정할 수 있는 위치는 저장소 안의 `progress/**`와 사용자가 정확히 지정한 `learning-notes/**`뿐이다. 다른 경로, 저장소 밖으로 빠져나가는 경로와 심볼릭 링크를 통한 우회는 허용하지 않는다.

예시:

```text
$learning-record-manager

아래 내용은 내가 검토한 최종본이야.
current-state에는 재개점과 남은 공백을 반영하고,
question-backlog에는 Q2만 추가해줘.
my-summary는 내가 직접 작성할 테니 건드리지 마.
```

## 기록하면 안 되는 것

- AI가 대신 쓴 설명을 자신의 무지원 설명으로 기록
- 참고 코드를 직접 구현한 결과로 기록
- 실행하지 않은 실험 결과나 테스트 통과 기록
- 이해하지 못한 내용을 완료로 기록
- 승인하지 않은 질문과 심화 주제를 자동 추가

기록을 잘 쓰는 것보다 실제 이해와 재개 가능성을 정확하게 남기는 것이 중요하다.
