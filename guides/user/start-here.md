# 여기서 시작하기

이 저장소는 AI가 정한 순서에 끌려가는 과정이 아니다. [커리큘럼](../../curriculum/overview.md)에서 현재 범위를 확인하고, 오늘 필요한 스킬을 직접 호출해 학습한다.

## 처음 시작하는 순서

1. [과정 안내](../../curriculum/overview.md)에서 현재 기준 과정을 확인한다.
2. [현재 진행 상태](../../progress/current-state.md)를 확인한다.
3. 처음이라면 0주차부터 시작할지, 이미 아는 내용을 먼저 진단할지 선택한다.
4. 오늘 가능한 시간과 원하는 범위를 정한다.
5. 필요한 스킬을 `$skill-name`으로 명시적으로 호출한다.

## 처음 위치를 모를 때: 사전 진단

Python 경험이 충분하더라도 ML·LLM 이해까지 건너뛰어도 된다는 뜻은 아니다. 시작 위치가 애매하면 0주차의 완료 기준과 누적 미니 테스트를 이용해 가볍게 진단한다.

```text
$retrieve-first-gate

0주차 완료 기준과 누적 미니 테스트 범위에서
자료 없이 현재 알고 있는 내용을 먼저 확인해줘.
정답이나 설명은 내가 답한 뒤에 보여줘.
```

진단 결과는 시작 주차를 선택할 근거일 뿐이다. AI가 주차를 자동 배정하거나 진단 통과만으로 완료 처리하지 않는다. 확인된 강점, 남은 공백과 원하는 안전 수준을 보고 사용자가 시작 위치를 선택한 다음 `$learning-session-planner`로 오늘 범위를 정한다.

첫 요청 예시:

```text
$learning-session-planner

0주차 1회차를 처음 시작하려고 해.
오늘은 2시간 사용할 수 있어.
자연스러운 중단 지점을 기준으로 최소·기준·확장 범위를 제안해줘.
```

AI가 제안한 범위를 보고 하나를 선택한 뒤 학습을 시작한다. AI는 범위를 대신 선택하지 않는다.

## AI가 맡는 일

- 가능한 시간에 맞는 범위와 중단점 제안
- 먼저 회상하고 설명하도록 질문
- 막힌 원인 진단과 단계별 힌트
- 작성한 코드와 답안 검토
- 핵심 이론과 출처의 일치 여부 확인
- 승인된 기록의 파일 반영

## 사용자가 맡는 일

- 오늘 학습할 범위와 도움 수준 선택
- 설명·설계·코드·답안을 먼저 작성
- AI 결과를 이해했는지 자기 말과 무지원 수행으로 확인
- 다음 주차 진행과 주제 완료 여부 결정
- 파일에 남길 기록을 검토하고 승인

## 기억할 규칙

- 스킬은 자동으로 작동하지 않는다. [호출 가이드](skill-invocation-guide.md)에서 목적에 맞는 스킬을 선택한다.
- AI가 대화에서 만든 정리는 파일 기록이 아니다.
- 참고 코드와 힌트를 받은 결과는 무지원 결과와 구분한다.
- 하루 종료와 주제 완료는 다르다. 여러 날 이어서 진행해도 된다.
- 핵심 이론의 사실 여부가 의심되면 `$ai-claim-checker`를 호출한다.
