# 개인 복습 기록

이 폴더는 사용자가 자신의 말로 학습 내용을 정리하는 공간이다. AI가 공식 진도처럼 자동 작성하지 않는다.

## 폴더 이름

실제 학습한 날 필요한 폴더만 만든다.

```text
week-XX/YYYY-MM-DD-topic/
```

예:

```text
week-02/2026-08-20-confusion-matrix/
```

## 선택 파일

- `my-summary.md`: 자신의 말로 쓴 개념과 흐름
- `recall.md`: 자료 없이 복원한 구조, 수식과 답변
- `experiment.md`: 예상, 조건, 실행 결과와 자신의 해석
- `questions.md`: 현재 질문, 추측과 확인 방법
- `review.md`: 복습 문제 답안, 받은 도움과 수정 설명

매번 다섯 파일을 모두 만들 필요는 없다. 학습 증거가 있는 파일만 만든다.

## AI 사용

- 먼저 자신이 작성한다.
- 검토가 필요하면 읽을 파일과 원하는 검토 범위를 명시한다.
- AI가 수정한 문장을 이해하지 못하면 자신의 학습 기록으로 확정하지 않는다.
- 파일 수정을 원하면 `$learning-record-manager`를 명시적으로 호출하고 반영 범위를 승인한다.
