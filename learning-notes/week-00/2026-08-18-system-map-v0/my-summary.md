# AI 시스템 지도 v0

## 사용자 작성

> 사용자의 요청이 들어오면 데이터. 문서에서 필요한 정보를 검색.
> 검색한 정보 기반 답변 생성. 앱 실행 검증 후 기능 실행.
> 결과를 기반 답변 생성. 근거. 비용 검증.

## 받은 AI 도움

- 전체 흐름과 구성 요소의 역할을 표로 설명받았다.
- 각 구성 요소를 `입력 → 역할 → 출력 → 대표 실패`로 정리하는 방법을 안내받았다.
- 게임 서버의 요청 처리 파이프라인처럼 생각하는 비유를 제공받았다.

이 내용은 AI 설명을 받은 뒤 작성한 보조 학습 결과이며, 무지원 회상 결과가 아니다.

## 아직 직접 작성하지 않은 부분

- 각 구성 요소의 입력과 출력
- 각 구성 요소의 대표 실패
- 상자와 화살표로 그린 전체 시스템 지도
- 검색 실패와 답변 생성 실패의 구분 설명
